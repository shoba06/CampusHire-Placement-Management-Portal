# CampusHire – Campus Placement & Recruitment Management Portal

> A connected campus placement and recruitment management portal that brings together student profiles, smart opportunity matching, applications, recruiter actions, status tracking, notifications, and analytics in one system.

## 📌 Project Overview

CampusHire is a web-based campus placement and recruitment management system designed to improve the traditional placement process.

Instead of handling student profiles, job opportunities, applications, recruiter actions, and updates as separate processes, CampusHire connects them into one complete workflow:

**Student Profile → Opportunity Matching → Application → Recruiter Decision → Student Update**

The system provides separate experiences for students and recruiters while using a PHP backend and MySQL database for dynamic data management.

---

## 🎯 Objectives

- Build a complete digital platform for campus placement management.
- Create a structured and placement-ready student profile.
- Match students with suitable opportunities using profile-based matching.
- Allow students to apply for opportunities and track application status.
- Allow recruiters to create opportunities and manage candidates.
- Provide application status tracking from Applied to Interview and Selection.
- Generate student notifications based on application updates.
- Provide recruiter-side analytics for placement activities.
